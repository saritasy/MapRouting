# 📦 Delivery Area Assignment System

A hub-based delivery management system built with **Vite + React (TypeScript)** and **MySQL**.  
Operators can select areas on a map and assign them to delivery boys, who can serve only within those zones.  

---

## 🚀 Features
- Hub operator dashboard  
- Map-based area selection  
- Assign delivery zones to delivery boys  
- Delivery boys restricted to their assigned areas  
- Efficient and structured delivery management  

---

## 🛠 Tech Stack
- **Frontend:** Vite + React (TypeScript)  
- **Backend/Database:** MySQL  
- **Mapping:** Interactive area selection
